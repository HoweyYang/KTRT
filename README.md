# KTRT（KillTimeRecitationTool）

> KillTimeRecitationTool 是一款本地优先的英语单词背诵工具：一页一个词，音标、词性、搭配、短语、同反义词、同根词全部摊开，还支持 AI 造句、四选一闯关和随手记笔记。它的灵感来源于作者备考 GRE 时对市面背词软件的不满：背词逻辑不符合自己的习惯，一个单词只给浅尝辄止的释义，还到处要付费、不给钱就看广告。于是自己动手写了一个顺手的，词库想导哪本就导哪本，数据只留在自己电脑上。

开发者：HoweyYueng。

> **v0.1.4a 更新**：新增「杀词」闯关（记词闯关 + 错题闯关，答错自动沉淀进错题本）；界面重构为 Codex 风格左侧栏 + 三主题一键切换；启用新 K 标志（中心空心菱形）；操作指南独立成页并内置 PDF 文档。详见 [CHANGELOG.md](CHANGELOG.md)。

## 它有什么不一样

- **AI 帮你造句，还帮你记住**：输入一句中文提示（比如「他努力弥补过错」），AI 用当前单词造出英文句、高亮目标词、配好中文翻译，存进你的造句收藏。提示词跟单词不搭？AI 会丢掉提示词，随机用这个词造一句。提示词相关？它可以用这个词的同根词或变形来造句，比如 abbreviate 变成 abbreviation，高亮照样标得出来。
- **想背哪本，背哪本**：GRE、雅思、四六级、法语……任何单词书，整理成 Excel / CSV / 纯文本就能导入；搭配、短语、同反义词、同根词这些「扩展信息」AI 自动补齐。
- **离线也能查词**：内置 ECDICT 离线词典（77 万词条），没网也能查。
- **读给你听**：edge-tts 语音朗读，英语有美音/英音、男声/女声四选，法语也有男女声；语速、音调、音量都能调。想要完全离线，切到浏览器语音就行。
- **数据只属于你**：SQLite 本地存储，进度、收藏、造句全在自己电脑上，不上传、不外泄。
- **不绑定任何 AI**：厂商、模型、Key 全部可自由切换（DeepSeek、豆包、GPT、Gemini、Claude、千问、Grok 等）。

## 功能一览

- **一页一词**：单词加粗置顶，音标、词性释义、搭配、短语、同义词、反义词、同根词一屏摊开，每个字段都能单独点 🔊 朗读。
- **进度与标记**：每个 List 一条进度条；不熟悉 / 收藏 / 已背 三个标记随便点；管理页按 书 → List 分组，支持搜索、按状态筛选、删除记录、清空单个 List 进度。
- **AI 自定义造句**：见上面「AI 帮你造句」。每词最多存 3 句，超了自动删最旧的；管理页能看到每个词的造句并单独删除。
- **离线词典**：单词卡下方一键查 ECDICT，释义、词形变化都有。
- **自定义查词典**：输入任意单词，离线词典速查；在已导入词书里的词可直接收藏；不在任何词书里的词，用 AI 按标准范式生成后加入「外部单词收藏册」，和其他词书一样能背、能导出。
- **单词笔记本**：每个词都能记 Markdown 笔记（`#`/`##` 标题、加粗、高亮），代码/展示双视图，显式保存；管理页可筛选、清空、导出笔记。
- **杀词闯关**：以 List 为单元的四选一匹配词性释义，每局乱序；答错自动标「不熟悉」并进错题本；错题闯关可多选 List 合并复习，答对可选移出错题本；记录每个 List 的历史最高分。
- **多格式导入**：Excel（【】扩展格式）、CSV、纯文本都能导；可以指定书名和语言，法语书导入后自动用法语语音朗读。导入页能直接删除整本词书。
- **导出词汇**：管理页按「不熟悉 / 收藏 / 一并」导出成 Excel，每行就是该词在词库里的完整一行，还能再导回来。
- **主题**：浅色 / 深色 / 深蓝高对比三套，侧边栏一键切换，默认深蓝高对比。
- **软件更新**：设置页两个按钮，一个查 GitHub 最新补丁（最新 commit），一个查最新 Release，有新版直接给下载链接。

## 为什么这么轻

这个程序不是 Electron。

Electron 会把整个 Chromium 浏览器内核打包进安装包，光内核就一两百 MB，装完内存也吃得多。KTRT 反着来：双击启动后，后台拉起一个只监听 `127.0.0.1:8000` 的本地 Python 服务，然后打开你电脑上已经装好的浏览器去访问它。浏览器是借的，不是带的。

所以安装包小、启动快、内存占用低。词库、离线词典、进度、收藏全在本地 SQLite 和 Excel 里，断网也能背词、查词、导出。这个设计牺牲不了多少体验，换来的是「装了就像没装」。

## 数据与安全

- **全本地**：进度、收藏、造句、笔记只存在你电脑上（安装版在 %APPDATA%\KTRT），不注册、不登录、不上传。
- **越用越聪明**：杀词答错的词自动进错题本并标「不熟悉」，错题闯关按 List 集中复习，你的学习数据反过来优化复习路径。
- **更新不碰数据**：更新只替换程序文件，词库和记录在独立目录，升级/重装不丢任何东西；升级前把数据目录复制一份更稳。

## 本地部署

- **一键安装**：从 [GitHub Releases](https://github.com/HoweyYang/KTRT/releases) 下载安装包，双击安装，桌面快捷方式自动建好。
- **数据在哪**：源码版在 `C:\KTRT\data`，安装版在 `%APPDATA%\KTRT`。词库、进度、收藏、造句、设置全在这个目录里。
- **备份和搬家**：把整个数据目录复制走就行。换电脑 = 装好程序 + 把目录拷回去。
- **127.0.0.1 是什么**：本机回环地址，只有你自己的电脑能访问。程序不开外网端口，别人连不进来。

## 私密性

- 学习记录不出这台电脑。
- API Key 自己填，存在本地数据库，想换厂商随时换（DeepSeek、豆包、GPT、Gemini、Claude、千问、Grok 都支持）。
- 联网只有两处：AI 造句（单词 + 你的中文提示词发给**你自己选的厂商**）和 edge-tts 朗读（文本发给微软语音服务）。
- 把网线拔了，背词、查词、进度、导出照常能用。

## 快速开始

**方式一：一键安装（推荐，无需 Python）**

从 [GitHub Releases](https://github.com/HoweyYang/KTRT/releases) 下载安装包，双击安装即可：

- `KTRTSetup-lite-0.1.3.exe`：纯净版安装包，不含任何词库；词库从仓库 `wordbooks/` 目录下载后到「导入」页导入。

安装后自动创建桌面快捷方式，启动即自动打开使用页面。

> **词库独立下载**：仓库 `wordbooks/` 目录提供 `GRE_Wordbook.xlsx`（GRE必背，6519 词）、`IELTS_Wordbook.xlsx`（雅思词汇真经，3608 词）与 `KAOYAN_Wordbook.xlsx`（考研英语词汇词根+联想记忆法，5905 词），
> 想背哪本下载哪本，到「导入」页手动导入即可（具体步骤见 [docs/使用教程.md](docs/使用教程.md)）。

**方式二：源码运行（开发）**

环境：Python 3.10+

```bash
# Windows：日常使用双击 KTRT.vbs（无终端）；调试用 KTRT.bat（控制台）
# 首次运行会自动建虚拟环境并安装依赖
# 或手动：
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python launcher.py
```

启动后浏览器打开 http://127.0.0.1:8000。

**方式三：Mac（源码运行）**

目前还没有 Mac 安装包，但核心是跨平台的，Mac 上可以源码直接跑：

```bash
# 需要 Python 3.10+
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python launcher.py
```

启动后浏览器自动打开 http://127.0.0.1:8000。Windows 专属的 VBS 与桌面快捷方式在 Mac 上不适用，直接用上面的命令即可；正式的 Mac 安装包（.app）后续会通过 GitHub Actions 云端打包发布。

> **API Key**：本项目不内置、不提交任何 API Key。首次使用请在「设置」页填写你自己的 Key，并可自由切换厂商/模型。

## 项目结构

```
KTRT.vbs            无终端启动（源码模式，日常用）
KTRT.bat            一键启动（控制台调试版）
splash.py           启动预备弹窗（进度条）
launcher.py         启动器（准备词库→启动服务→打开浏览器）
backend/            FastAPI 后端（数据库/导入/AI/朗读/更新检查）
frontend/static/    前端页面（原生 HTML/CSS/JS）
data/               本地数据（不入库，见 data/README.md）
docs/               设计文档、路线图、教程
```
