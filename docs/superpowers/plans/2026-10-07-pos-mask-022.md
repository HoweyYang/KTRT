# 词性判定 / 蒙版自适应 / 离线参考库（0.2.2）实施计划

> 依据：`docs/superpowers/specs/2026-10-06-pos-mask-design.md`、
> `docs/superpowers/specs/2026-10-07-reference-dictionaries-candidates.md`

## 文件结构

| 文件 | 职责 |
| --- | --- |
| `backend/db.py` | 新增 `words.pos_tags/pos_source` 列与 `word_pos_cache`、`word_pos_override` 表；老库迁移 |
| `backend/pos.py` | 五级判定链、闭集表、名词/动词子类；读写缓存与手动覆盖 |
| `backend/reflib.py`（新） | 离线参考库：增强包（Moby/WordNet）读取、启用状态、学科库占位 |
| `backend/lookup.py`（新） | **统一检索层** `lookup()`：多源合并、来源标注、异常隔离、缓存 |
| `backend/app.py` | 导入时判定、`/api/pos/*`、`/api/reflib/*`、查词/风暴改走 `lookup()` |
| `frontend/static/app.js` + `index.html` | 词卡芯片与原文释义区、蒙版粗桶、导入体检卡、待确认清单、离线参考库分区 |
| `tests/db_test.py` | 判定链、检索层、参考库降级、override 不回写 Excel 的回归 |

## 任务

### T1 数据层（0.5 天）

1. 写失败测试：新库应存在 `words.pos_tags/pos_source` 与两张新表；旧库 `init_db()` 后自动补列。
2. `db.py` 加迁移（沿用现有 `PRAGMA table_info` 判列写法）。
3. 跑 `tests/db_test.py`，旧用例不回归。
4. 提交。

### T2 判定链（1 天）

1. 写失败测试：`become→vi.+系动词`、`let→vt.+使役`、`must→情态`、`run→vt.+vi.`、`Atlantic→专有名词`、`abstruse→形容词`、生造词→待确认。
2. `pos.py` 实现五级：① 释义显式标记 ② ECDICT 按行义项 ③ 中文关键词 ④ 闭集表（系/情态/助动/使役）⑤ 待确认；输出统一 `tags` 结构（含动词子类、名词子类）。
3. 缓存：`word_pos_cache` 读写；重复判定不重算。
4. 测试通过后提交。

### T3 统一检索层（1 天）

1. 写失败测试：回归词 `bus / buses / accede / phenomena / clan / abstruse / be for / El Nino / carbon dioxide` 全部能查到；`lookup()` 返回来源标注。
2. `lookup.py`：来源优先级 ECDICT → 增强包 → 参考库 → 词书 → 在线（默认关）；合并去重；单源异常隔离；未命中给拼写/原形/拆词建议；`depth` 参数区分简查/全查。
3. 异常场景测试：增强包未装、参考库文件损坏、参考库全禁用 —— 检索仍返回结果且不报错。
4. 把 `/api/custom-dict/lookup`、卡片查词典、风暴素材、蒙版判定改为调用 `lookup()`。
5. 提交。

### T4 词卡（0.5 天）

1. 词性芯片（含动词子类 / 专有名词 / 可数）；原文释义单独成区、中英并排、默认展开。
2. 蒙版生成的词书卡片同样显示（生成时复制 `pos_tags`）。
3. 截图验收 + 提交。

### T5 蒙版界面（0.5 天）

1. 七个粗桶：名词性 / 动词 / 形容词 / 副词 / 虚词（介词·连词）/ 其他（短语·感叹）/ 待确认。
2. 生成词书复制 `pos_tags`、计数与跳转照旧。
3. 提交。

### T6 导入体检 + 待确认清单（1 天）

1. 导入结果返回计数；界面出体检卡。
2. 待确认清单：逐条改 + 批量设；写 `word_pos_override`，**不写回 Excel**（测试断言词书文件 mtime 不变）。
3. 提交。

### T7 离线参考库分区 + 增强包（1 天）

1. 导入页新增「离线参考库」：内置 ECDICT、可下载增强包、本机导入；启用/禁用。
2. 用 Moby + WordNet 生成 `refpos.db`（词性 + 英文 gloss），本地先跑通；GitHub 资源发布留到确认体积后再做。
3. 提交。

### T8 AI 兜底（0.5 天）

1. 只对「待确认」批量（≤100 词）调用；断网/无 Key 自动跳过。
2. 结果写缓存并标 `ai`；mock 测试 + 真机离线测试。
3. 提交。

### T9 文档与版本（0.5 天）

1. CHANGELOG / README / 使用教程 / 发布说明更新；说明 PDF 重新生成。
2. 版本 0.2.2，重建安装包；发布前跑完整回归（单测 + 回归词清单 + 真机雅思/GRE 对比 + 截图）。
