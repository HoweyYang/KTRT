# 词性判定 + 导入体检 + 词性蒙版自适应（设计）

日期：2026-10-06　版本：0.2.2（功能版）

## 目标

把"词性蒙版"从"只认显式标记的粗筛"升级成"程序内自适应判定 + 可复核"：

1. 判定更细：动词拆到 及物 / 不及物 / 兼类 / 系动词 / 情态 / 助动词 / 使役（L1 + L2，一次做完）。
2. 判定更全：判不出来的不再静默归「其他」，而是标成「待确认」。
3. 全程在程序里：**不改词书文件、不回写 Excel**；筛选产出的是程序内的新词书。
4. 可复核：导入时给出体检计数，需要时再看"待确认清单"，改也只是改程序里的判定。

## 判定链（导入时跑一次，记来源与置信度）

| 顺序 | 依据 | 置信度 |
| --- | --- | --- |
| ① | 词书释义里的显式标记（`vi. / vt. / adj. …`，已做同义归并） | 高 |
| ② | ECDICT `translation` 按行义项（其格式本身按词性分行）+ `definition` | 中高 |
| ③ | 中文释义关键词（使/让/令 → 使役；变得/显得/保持/仍然 → 系动词） | 中 |
| ④ | 闭集表（系动词、情态、助动词、使役四张内置表） | 高 |
| ⑤ | 仍判不出 → `pos_source=todo`（待确认） | 低 |

可选兜底（用户选择 B）：只对「待确认」的词批量问一次 AI（每批 ≤100 词，返回 词 / 词性 / 动词子类 / 理由），
结果标 `pos_source=ai`；**断网自动跳过**，绝不自动跑。

## 数据模型（只加列加表，不动现有字段与词库文件）

- `words.pos_tags TEXT DEFAULT ''`：`|` 分隔，如 `n|v:vt|v:caus`。
- `words.pos_source TEXT DEFAULT ''`：`book | dict | rule | table | ai | todo`。
- `word_pos_cache(word PRIMARY KEY, tags, source, updated_at)`：**按词缓存**，同词跨书只判一次。
- `word_pos_override(word PRIMARY KEY, tags, updated_at)`：只有用户手动改过才有记录，优先级最高。

## 蒙版界面（平铺，不再折叠）

选项全部同级列出：名词、动词、形容词、副词、介词、连词、代词、数词、冠词、感叹词、缩写、短语、待确认
＋ 动词子类：及物、不及物、兼类、系动词、情态动词、助动词、使役动词。

- 多选 = 或；「动词」= 所有子类的并集。
- 列表里每个桶显示计数；「待确认」悬停说明：释义没标、词典也没查到、AI 也未判。
- 生成时可选"只保留命中的义项"（默认保留整词）；生成的词条带词性芯片（`v.(及物) · n.`）。
- 生成物是程序内的普通词书：学词 / 杀词 / 进度 / 错题 / 笔记 / 导出照常，卡片可跳回原书位置。

## 导入体检

导入完成后返回一张卡：`自带标记 x · 词典补全 y · 规则/闭集表 z · 待确认 w`，
点「查看待确认清单」列出 词 / 释义 / 当前判断 / 依据 / 置信度；可逐条改或多选批量设。
**修正只写进 `word_pos_override`，不碰词书文件、不回写 Excel。**

## 不做（本版 YAGNI）

- 不写回词书 Excel、不改 wordbooks/ 里的文件。
- 不做 L3 后接模式（`+that / +doing / +to do / +sb to do`）—— 字段与判定链留好位置，下一版再谈。
- 不用 Collins 星级做筛选项（数据只有 1.8% 覆盖，太稀疏）。
- 不自动调用 AI。
