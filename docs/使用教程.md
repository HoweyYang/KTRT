# KTRT 使用教程（溯源词斩 · KillTimeRecitationTool v0.2.0d）

开发者：HoweyYueng。本程序是本地优先的背单词网页应用，词汇数据全部存在你自己的电脑上。

> v0.2.0a 是**首个正式版**，b / c / d 是它上面的修订版（0.1.0 – 0.1.6b 为开源内测版）。安装包内的《KTRT 使用说明（PDF）》与本文件内容一致。

## 一、安装与启动

1. 双击安装包 `KTRTSetup-lite-0.2.0d.exe`，安装器会让你选语言（简体中文 / 繁体中文 / 英语），一路下一步。
2. 装完自动创建桌面快捷方式；纯净版安装包**不含词库**，词库见第三节。
3. 双击桌面「KTRT」启动：先出现预备窗口（准备词库、拉起本地服务），随后浏览器自动打开 http://127.0.0.1:8000 。
4. 程序在后台常驻，没有终端黑窗；关闭浏览器标签不影响使用，同一时间只跑一个实例。
5. 想彻底退出：任务管理器结束 `pythonw.exe`（源码版）或 `KTRT.exe`（安装版）进程。

## 二、接入 AI

AI 用在三处：**单词造句、风暴词卡生成、自定义查词的机翻与添加新词条**。不填 Key 也能背词、查离线词典、闯关、记笔记。

1. 打开「设置」页。
2. 「模型厂商」选 **DeepSeek**，Base URL 与模型名保持默认（`https://api.deepseek.com` 与 `deepseek-chat`）。
3. 在「API Key」里填入你的 Key：随包发放的《KTRT 使用说明》PDF 里有一枚**测试 Key**，可直接粘贴体验；长期使用请换成自己在厂商开放平台申请的 Key（DeepSeek / 豆包 / GPT / Gemini / Claude / 千问 / Grok 均可，厂商与模型随时可换）。
4. 点「保存设置」，再点「测试 AI」，提示连接成功即完成。

## 三、导入词库

程序自带三本整理好的词库：

| 词书 | 词数 | 文件 |
|---|---|---|
| GRE 必背 | 6519 | `GRE_Wordbook.xlsx` |
| 雅思词汇真经 | 3608 | `IELTS_Wordbook.xlsx` |
| 考研英语词汇词根+联想记忆法 | 5905 | `KAOYAN_Wordbook.xlsx` |

- **下载**：「导入」页 →「词书资源」区点对应「下载」，或到仓库 `wordbooks/` 目录下载。
- **导入**：「选择文件」挑 xlsx →「单词书名」可留空（默认取文件名）→「语言」选英语 → 点「导入」，提示“导入成功：xxx，N 词”即完成。
- **自制词书**：把手上的单词书（Excel / PDF / Word / 图片 / 电子书）交给 AI，点「导入」页的「复制自制词书提示词」，让它按 11 列【】格式整理成 Excel 再导入（提示词全文见 `frontend/static/docs/词书整理提示词.md`）。
- 支持 xlsx / CSV / 纯文本；重复导入同名书按 List + 序号覆盖更新，不会越导越多；已导入的书可删除（默认书除外）。

## 四、学词页

- 顶部选**单词书**和 **List**，进度条显示已背 / 总数；键盘 ← / → 翻词。
- 单词卡：单词加粗置顶，下面是音标、词性释义、**搭配与短语**（合并为一栏，本词优先 → 更短优先 → 字母序）、同义词、反义词、同根词；每个字段旁的朗读键可单独读那一行。
- **动词短语参考**：内置动词短语库 2217 条 / 3214 个义项（中文释义、例句中译、语域、学习价值），导入词书时按动词自动检索写入，卡片下方直接列出并可展开；名词不参与检索。
- 标记与进度：「背」计入进度并跳下一个；「熟悉 / 不熟悉 / 收藏」可组合点、再点取消；小书签一键留标记，顶部下拉直达；每本书各自记住上次学到哪。
- **编辑词条**：音标右侧铅笔图标，就地改这一条（单词、音标、词性释义、搭配、短语、同义词、反义词、同根词），保存后同步本地数据库并**回写这本词书的 Excel 对应行**；原文件被移动 / 删除时自动写到 `data/wordbooks` 下的托管副本。发现音标或释义有误直接改这里。
- AI 造句：输入中文提示（如“他努力弥补过错”）→「生成造句」，高亮目标词并配中文翻译，存入造句收藏，每词最多 3 句。
- 查词典：卡片下方「查词典」用内置 ECDICT 离线词典速查，断网可用。
- 单词笔记本：卡片右侧写 Markdown 笔记（行首 `#` / `##` 变标题，`Ctrl+B` 加粗，选中右键高亮），点「保存」生效；**笔记按词共用**（同一个词在几本词书里是同一份笔记），导出时仍按词书分别导出。

## 五、查词与风暴词卡

**自定义查词典**（学词页顶部按钮）：

- 输入英文单词 / 短语 / 句子，或直接输中文（自动中↔英机翻），点「查询」。
- 结果依次为：离线词典释义 → 机翻 → Datamuse 在线联想（同音近音、形似词，查询后自动加载）。
- 结果下方列出这个词**所在词书**，点词书芯片直接跳到那本书对应的 List 与序号。
- 「+ 添加到外部单词收藏册」：单词按原形入库（大小写、复数等自动归一），之后和普通词书一样能背、能导出；短语或句子只保留释义条目（类型 + 译文 + 使用场景 + 拆解）。
- 「风暴词卡」按钮：已有词卡就地预览，没有则跳风暴页生成。

**风暴词卡页**：输入单词生成结构化词卡（百科词源、使用场景、释义、词形变化、搭配、介词搭配、短语、俚语习语、衍生词、同义词 / 近义词、反义词、形似易混淆词），可单条或批量导出 Excel / Markdown；词卡里的词书芯片同样可点，方便定位它在哪本书里。

## 六、杀词（闯关）

- 记词闯关：以 List 为最小单元四选一，每局乱序；答错自动标「不熟悉」并即时进错题本；记录每个 List 最高分。
- 错题闯关：可多选 List 合并题池，答对可选移出错题本。
- 答题中进入专注模式；切页清空本局进度，已进错题本的词保留。

## 七、管理页

- 搜索框按单词 / 音标即时过滤；下拉按 熟悉 / 不熟悉 / 收藏 / 已背 / 有造句 / 有笔记 筛选。
- 列表按 单词书 → List 分组，可折叠；每行可删除该词的学习记录。
- 导出：选范围（不熟悉 / 收藏 / 一并）+ 词书 + List 导成 Excel，每行是该词在词库里的完整一行，还能再导回来；「导出笔记」导 Markdown。
- 清空进度：按词书 + List 清空「已背」，收藏 / 熟悉 / 笔记不受影响；另可单独清空笔记。

## 八、设置页

1. **界面质感 × 配色**：三种页面质感，每种质感各三套配色，侧栏三个颜色按钮随质感自动换名。

| 页面质感 | 配色一 | 配色二 | 配色三 |
|---|---|---|---|
| 简约（Apple / OpenAI 风） | 浅色 | 深色 | 石墨 |
| 纸质（纸纹 + 衬线字体） | 米白纸 | 牛皮纸 | 靛蓝纸 |
| 科幻（霓虹夜景 / 扫描线） | 霓虹 | 酸黄 | 矩阵 |

2. **AI 配置**：厂商 / Base URL / 模型名 / API Key，「保存设置」后可用「测试 AI」验证。
3. **朗读**：edge-tts（联网，音质好）或浏览器语音（完全离线）；英语美音 / 英音 × 男 / 女四选，法语男 / 女声；语速、音调、音量可调；连点朗读键不会叠音。

## 九、更新页

- 「检查更新」读取 GitHub 上的最新发布：**有热补丁就一键应用**，不用重启，刷新页面即生效；**有新版本就下载安装包并静默安装**，装完自动重开（会弹一次系统授权框，点"是"即可）。
- 「启动时自动检查更新」默认打开：有新版或补丁会在开程序时弹窗提示，可以选「稍后」或「本版本不再提醒」。
- 源码版不提供一键安装：检查到新版本会给出 Release 页面链接，自行 `git pull` 或下载。
- 补丁包与安装包都来自本项目的 GitHub Release；热补丁不需要管理员权限，安装包更新也不会动 `data` 目录里的学习数据。

## 十、数据、备份与隐私

- 数据目录：安装版 `%APPDATA%\KTRT`，源码版 `C:\KTRT\data`。内含 `ktrt.db`（进度 / 收藏 / 造句 / 笔记 / 设置）、`dictionary.db`（ECDICT 离线词典）、`phrasal_verbs.json`（动词短语库）、`wordbooks`（导入的词书副本）。
- 备份 / 换电脑：复制整个数据目录即可；升级、重装不碰这个目录。
- 联网只有两处：AI 相关功能（发给你自己配置的厂商）和 edge-tts 朗读（发给微软语音服务）；断网也能背词、查词典、闯关、记笔记、导出。

## 十一、注意事项与常见问题

- 不要同时开两个 KTRT；不要删 / 移 `data` 目录；导入或编辑词书前先关掉 Excel / WPS。
- 改了设置或换了词书后界面没变化：按 **Ctrl + F5** 强制刷新；还不行就退出程序重开。
- AI 报错：先点「测试 AI」检查 Key / 欠费 / 网络；换网络或代理后重开程序再试。
- 朗读没声音：edge-tts 需要联网，或到设置页换成「浏览器语音」。
- 网页打不开：确认程序启动完成（约 3 秒），手动访问 http://127.0.0.1:8000 ；提示端口被占用说明已有一个实例在跑。
- 杀毒 / 网盘同步软件不要实时扫描数据目录，避免锁住数据库文件。
- 词书里的音标 / 释义有错：用学词页铅笔图标就地改，保存后写回词书 Excel 对应行。
