# KTRT 使用教程（KillTimeRecitationTool）

开发者：HoweyYueng。本程序是本地背单词网页应用，数据全部存在你的电脑上。

## 一、启动与关闭

1. 双击桌面的 `KTRT.lnk`（或 `C:\KTRT\KTRT.bat`）。
2. 会自动弹出黑色命令行窗口，并在浏览器打开 http://127.0.0.1:8000 。
3. **关闭程序 = 关闭那个黑色窗口**（浏览器标签页可以随时关，不影响）。
4. 最新版本v0.1.2，已经消除黑色**终端窗口**，默认深色蓝主题，支持美音/英音与男/女声朗读，且优化了UI。

> 首次启动会自动准备词库（GRE必背、词典、参考素材），之后启动都是秒开。

## 二、学习页

- 顶部选择**单词书**和 **List**；进度条显示“已背/总数”。
- 单词卡：加粗单词 + 音标 + 词性释义 + 搭配 + 短语 + 同义词 + 反义词 + 同根词 + 动词短语参考。
- 按钮：
  - `背`：计入进度并跳到下一个；
  - `熟悉 / 不熟悉 / 收藏`：可组合标记，点击再点取消；
  - `← 上一个 / 下一个 →`，也可用键盘左右方向键。
- 朗读：点任意字段旁的 🔊；单词按钮朗读“单词+音标”。
- 查词典：点“📖 查词典”查看 ECDICT 离线词典释义。
- 造句：在输入框写中文提示，点“生成造句”；每词最多 3 句、超出自动删最旧；句子会高亮目标词并存入收藏。

## 三、管理页

- 搜索框：按单词或音标即时过滤。
- 筛选：熟悉 / 不熟悉 / 收藏 / 已背 / 有造句 / 全部。
- 列表按“单词书 → List”分组，可折叠；每行可“删除记录”。
- “清空进度”：选择单词书和 List 后清空该 List 的“已背”（收藏/熟悉保留）。
- 句子管理：句子数大于 0 时点“查看”可展开并删除造句。

## 四、导入页

- 支持格式：
  - `【】格式 Excel`（标准 11 列）；
  - `CSV`（含表头或纯单词）；
  - `纯文本`（每行一个单词；可用 Tab 分隔“单词/音标/释义”）。
- 书名留空时使用表内【单词书】列或文件名；语言决定朗读语音。
- “已导入的单词书”区可**删除**任意非默认书（GRE必背 为默认书不可删）。
- 重复导入同名书会按 List+序号覆盖更新，不会叠加。

## 五、设置页

- 界面主题：浅色 / 深色·蓝 / 深色·高对比。
- AI 配置：厂商下拉（DeepSeek/豆包/GPT/Gemini/Claude/千问/Grok）、Base URL、模型、API Key；可“测试 AI”。
- 朗读方式：edge-tts（联网、音质好）或浏览器语音（离线）。

## 六、数据与备份

所有数据在 `C:\KTRT\data`：

| 文件 | 内容 |
|---|---|
| `ktrt.db` | 学习记录：进度、状态、收藏、造句、设置 |
| `dictionary.db` | ECDICT 离线词典（77 万词条） |
| `GRE必背_扩展词库.xlsx` | GRE 扩展词库 |
| `reference_phrasal_verbs.json` | 动词短语参考素材（3217 条） |
| `config.json` | 默认 API Key 等配置 |

备份时复制 `ktrt.db` 即可带走全部学习记录。

## 七、常见问题

- **浏览器打不开/拒绝连接**：说明服务没在运行，双击 `KTRT.bat` 重新启动；确认黑色窗口还开着。
- **朗读没声音**：edge-tts 需要联网；断网时到设置切“浏览器语音”。
- **造句失败**：检查设置里的 API Key、Base URL 和模型，点“测试 AI”。
- **端口被占用**：关闭旧的黑色窗口再启动。

更详细的词库制作方法见《Excel生成教程.md》。
