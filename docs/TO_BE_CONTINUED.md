## 一、已完成（截至 v0.1.6）

### 形态与发布

- 本地网页应用：FastAPI + SQLite + 原生 HTML/CSS/JS，仅监听 `127.0.0.1:8000`，无 Electron、不打包浏览器内核。
- Windows 安装包（PyInstaller + Inno Setup，lite 纯净版、不含词库）；桌面快捷方式、启动动画、无终端启动、单实例保护。
- 发布双通道：小补丁直推 main，正式版本才打 tag + Release；Release 只放 lite 安装包，词库在仓库 `wordbooks/` 独立下载。
- 安装向导支持简体中文 / 繁体中文 / 英语三种语言（注意：仅安装向导，程序界面目前为简体中文）。

### 词库与数据

- 三本词库：GRE必背 6519 词、雅思词汇真经 3608 词、考研英语词汇词根+联想记忆法 5905 词；均按 11 列【】GRE 规范整理。
- 雅思 / 考研「搭配、短语」按 GRE 格式补全中文翻译，雅思源文件水印广告已清理；GRE 同根词修复与清洗已完成。
- 可复用词库管线：`tools/enrich_workbook.py`（水印清理 + 搭配/短语翻译 + 断点续跑 + 数据库回写）。
- 导入支持 Excel（【】格式）/ CSV / 纯文本；支持多语言词书（语言决定朗读语音）。

### 学习体验

- 一页一词：单词、音标、词性释义、搭配、短语、同义词、反义词、同根词。
- 状态与进度：不熟悉 / 收藏 / 已背三个独立标记（已背与不熟悉互斥），List 进度条，管理页筛选、导出、清空。
- 位置记忆：每本书分别记住 List + 序号，切换词书自动回到原处。
- 书签：单词卡内书签图标一键留取，顶部下拉直达任意书签位置。
- AI 造句：提示词相关/无关两套规则，同根词与变形高亮，每词最多 3 句。
- 笔记本：单词卡右侧，单层所见即所得 Markdown（`#`/`##` 标题、Ctrl+B/I、右键高亮），显式保存，管理页可筛选/清空/导出。
- 朗读：edge-tts（英/法、美英音 × 男女声）与浏览器语音兜底；语速、音调、音量可调；不读音标与中文。
- 主题两轴：页面质感（普通 / 纸质）× 主题色（浅色 / 深色 / 深蓝）共 6 套；侧栏可收缩；极简图标 UI + 全页悬停功能引导。

### 杀词（闯关复习）

- 记词闯关：以 List 为单元，四选一匹配词性释义，选项与题序乱序，记录历史最高分。
- 错题闯关：错题按词书 × List 组织，可多选 List 合并题池，答对后自行决定移出或保留。
- 答错自动标记「不熟悉」并入错题本；已背的词不再出现在杀词题池。

### 查词与检索

- 离线 ECDICT（约 77 万词条）速查；词形代码已翻译为中文（原形/复数/过去式等）。
- 原形归一：`phenomena → phenomenon`、`went → go` 等，查词/收藏/添加统一按原形执行。
- 本地拼写纠错：「您是不是想搜」候选（无需联网、不耗 AI）。
- 在线词源（免费开源）：Wiktionary 释义 + Datamuse 相关/同音/形似词，8 秒超时、失败降级。
- 支持单词、短语、短句、习语、俚语：无词数上限（≤200 字符），自动拆词取义，AI 翻译/整理成统一词条格式；缺同根/变形则留空，不编造。
- AI 翻译 / 整理结果可一键加入「外部单词收藏册」，完整文本同时存入笔记。

### 单词风暴（词卡）

- 生成管线：本地词库（ECDICT + 词书 + 动词短语素材 + 形近候选）→ 免费开源在线词源 → AI 按固定 schema 生成。
- 词卡内容：百科词源、使用场景、释义、词形变化、搭配、介词搭配、短语、俚语/习语、衍生词、同义/近义（含语义区别）、反义词、形似易混淆词。
- 逐词判断易混词数量；专有名词大小写自纠正（rome→Rome）；结果规整与词形代码过滤。
- 独立存储（`storm_entries`），与词书互不覆盖；侧栏「风暴词卡」页 + 学词页闪电入口；覆盖式弹层查看、按词搜索、单/批量导出 Excel / Markdown。

### 工程与治理

- 更新检查：补丁（main commit）+ 版本（Release）双通道；并发请求、系统代理识别（Clash 等）、超时兜底。
- 词条格式规定（单词/短语/短句/习语/俚语统一 11 列结构、缺项留空）已写入手册第 6.7 节。
- 数据本地化：进度/收藏/造句/笔记/书签/风暴词卡全部在 `%APPDATA%\KTRT`（源码版为 `data/`），升级不覆盖。
