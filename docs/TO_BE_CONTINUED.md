- 深色主题、管理页按书/List 分组 + 搜索、学习状态/进度/收藏/造句管理。

## 方向一：增加资源，构建校验语料库

目标：让词条数据可交叉验证、可溯源、可信，成为“背词”与“查词”的可靠地基。

### 1. 多源资源接入
- 词典类：ECDICT（已有）、COCA/BNC 词频表、四六级/雅思/托福/GRE 大纲词表、词形变化表。
- 语料类：真题文本、教材语料、新闻语料（为方向二提供真实例句来源）。
- 参考素材类：已提取的动词短语库（3217 条）接入单词卡，后续可扩展习语、固定搭配、近义辨析素材。

### 2. 校验规则引擎
- 音标一致性：同一词多源 IPA 比对，标记差异。
- 释义覆盖度：词条命中 N 个词典即置信度高；单源或缺失 → 标记“待核”。
- 词性冲突检测：多源词性不一致时列出供人工确认。
- 拼写/词形校验：与词形变化表比对，提示疑似拼写错误。
- 导入即校验：每次导入生成《校验报告》（总词数、覆盖率、冲突数、缺失字段清单）。

### 3. 反馈回路
- 学习中增加“纠错”入口，反馈进入待审队列；审定的修正合并回语料库。
- 校验报告与修正记录留档，保证数据可追溯。

## 方向二：LLM Wiki 技术，增强背景资源关联性

目标：从“背一个词”升级为“进入一张词与知识的关系网”。

### 1. 词 Wiki 页
- 每个词自动生成 Wiki 卡片：词源与词根词缀、语义演变、考试语境、常见误用、文化背景、真题/语料例句出处。
- 全部内容标注来源（词典/语料/AI 生成），AI 内容明确标注“参考信息，以词典为准”。
- 批量生成 + 抽检机制（按 10% 抽检，控制幻觉与成本）。

### 2. 词间知识图谱
- 以同义词 / 反义词 / 同根词 / 常用搭配构建关系网络，可视化图谱。
- 从任意词一键跳到关联词，形成“一词连多词”的背词路径。

### 3. RAG 检索增强
- 背景资源库（真题、教材、语料）建立索引，按词检索真实例句与搭配。
- “这个词出现在哪些真题/文章里”成为可查询能力，辅助语境记忆。

### 4. 个人 Wiki
- 用户的造句、收藏、笔记按词聚合，形成个人专属记忆 Wiki，与公共数据并列展示。

## 方向三：多端形态（不只限于网页端）

### 1. exe 桌面程序
- PyInstaller 打包为免 Python 环境的独立程序，双击即用；或改用 Tauri 获得更小的体积与更现代的体验。
- 数据随本地 SQLite 迁移，离线可用。

### 2. 网站（部署版）
- 云服务器 + HTTPS + 账号系统，多设备同步学习记录/收藏/造句。
- 支持分享：词单、收藏、造句卡片对外展示。

### 3. 微信小程序
- 微信云开发（免自建服务器），小程序 TTS 组件朗读，每日打卡与分享卡片。
- 与网站共用同一数据协议与词库格式。

### 4. 移动端（后续）
- Tauri / Flutter 打包 iOS / Android，作为学习场景的补充入口。

## 各端共用底座

- 统一词书格式（Excel/JSON 标准，已在导入功能中定义）。
- 统一学习记录协议（进度/收藏/造句），云端同步时按词书隔离。
- 校验语料库、词 Wiki、知识图谱作为共享数据层，任何端都可复用。

## 里程碑建议（顺序）

1. M1 校验语料库 v1：多源导入 + 校验报告 + 纠错队列。
2. M2 词 Wiki 与知识图谱 v1：LLM 批量生成 + 关系可视化。
3. M3 exe 打包发布：独立桌面程序。
4. M4 网站部署：账号 + 多设备同步 + 分享。
5. M5 微信小程序 v1：云开发 + 打卡分享。
