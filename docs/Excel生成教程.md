# 把单词书（PDF/电子书）变成可导入的 Excel

目标：把任意单词书整理成 KTRT 标准格式，导入即可背诵。

## 一、标准格式（11 列）

| 列名 | 必填 | 说明 |
|---|---|---|
| 【单词】 | 是 | 英文单词或短语 |
| 【音标】 | 否 | IPA，可留空 |
| 【词性释义】 | 否 | 如 `n. 名词；v. 动词` |
| 【搭配】 | 否 | 多条用中文分号 `；` 分隔 |
| 【短语】 | 否 | 多条用 `；` 分隔 |
| 【同义词】 | 否 | 多条用 `；` 分隔 |
| 【反义词】 | 否 | 多条用 `；` 分隔 |
| 【同根词】 | 否 | 派生词族 |
| 【List】 | 否 | 第几单元/List，缺省为 1 |
| 【语言】 | 否 | 英语/法语…，决定朗读语音 |
| 【单词书】 | 否 | 书名，留空则用文件名 |

## 二、三种来源的做法

### A. 纯单词列表（最省事）
每行一个单词，存成 `.txt` 或 `.csv`，直接导入即可（语言和书名在导入页指定）。
也可以用 Tab 分隔三列：`单词<Tab>音标<Tab>释义`。

### B. 电子书（EPUB/网页/可复制的 PDF）
1. 打开电子书，把单词表区域的内容**复制成文本**（能选中文字即可）。
2. 把文本粘贴给 AI（DeepSeek/ChatGPT），用下面的“提取提示词”。
3. 把 AI 输出的表格内容复制进 Excel/WPS，保存为 `.xlsx`。

### C. 扫描版 PDF（图片）
1. 先 OCR：可用 WPS/Office 的 OCR、或把 PDF 转成可复制文本的工具（如 Adobe、腾讯文档）。
2. 得到文本后，同 B 步骤交给 AI 整理。

## 三、可直接复制的 AI 提示词

### 提示词 1：从文本提取为标准词表
```
你是英语词汇整理助手。下面是一份单词表文本（可能排版混乱、夹杂序号和无关内容）。
请提取所有英文单词，整理成表格，每行一个词，包含：单词、音标（IPA，没有就留空）、
词性+中文释义。列名严格使用：【单词】【音标】【词性释义】。
删除序号、页眉页脚、广告、重复词。只输出表格内容，不要解释。

文本如下：
<<在这里粘贴单词表文本>>
```

### 提示词 2：按章节/List 分组
```
继续上面的表格，新增两列【List】和【单词书】。
【List】按原文的单元/章节编号填写（没有就都填 1）；
【单词书】填 <<书名>>；【语言】填 英语。
输出完整表格。
```

### 提示词 3：批量补全音标/搭配/短语/同反义词/同根词
```
你是英语词汇编辑。下面每个词，请输出：
p=国际音标；c=2个常见搭配；ph=2个常见短语；s=2个同义词；
a=1-2个反义词（没有就写空数组）；r=2-3个同根词。
只输出一个 JSON 对象，不要任何其他文字：
{"单词": {"p":"音标","c":["搭配1","搭配2"],"ph":["短语1","短语2"],
"s":["同义1","同义2"],"a":["反义1"],"r":["同根1","同根2"]}, ...}

词表：<<粘贴单词列表>>
```

## 四、保存与导入

1. 把 AI 输出的内容粘贴到 Excel/WPS 第一行放列名，第二行起放数据。
2. 另存为 `.xlsx`（UTF-8）。
3. 在 KTRT“导入”页上传该文件；书名可留空（用表内【单词书】列）。
4. 导入成功后，学习页下拉就能看到新书。

## 五、小技巧

- 列可以少但不能改名字；`【单词】`必须有。
- 多值字段用中文分号 `；`，导入后会自动变成一行里的多个条目。
- 只想快速试：建一个两列文件 `【单词】 / 【词性释义】` 就能导入。
- 想全自动：把 EPUB 转成文本后让 AI 一次完成“提取+补全”，参考上面 1+3 两个提示词连用。
