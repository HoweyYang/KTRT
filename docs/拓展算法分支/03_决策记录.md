## 2. 评估方案（备选清单，针对“好坏判定”）

目标：量化“拓展”算法的好坏——既要看“该拓展的有没有找对”，也要看“不该拓展的是否被正确留空”。

### 2.1 评测数据集（备选）

| 数据集 | 规模/内容 | 作用 |
|--------|-----------|------|
| 自建金标准（gold set） | 从 GRE/雅思词库抽样 100–300 词，人工标注“拓展是否命中、是否多余” | **最贴合你的词库，建议优先做** |
| EPIE Corpus | 717 习语 / 25,206 句，含字面/非字面上下文 | 通用习语识别能力 |
| VNC-Tokens | 动词-名词搭配的字面/非字面标注 | 搭配类“拓展” |
| SemEval-2013 Task 5b | 习语检测基准 | 习语检测 |
| DiMSUM / PARSEME | 多词表达（MWE）序列标注 | 短语动词/多词表达 |

### 2.2 指标（备选）

- **精确率 / 召回率 / F1**：对“拓展”命中是否准确、是否漏。
- **Recall@K / MRR**：排序质量（呼应你 HNSWPQ 论文里的 Recall@10 口径）。
- **覆盖率**：多少词被正确判定“无拓展”而留空（避免硬凑）。
- **人工评分（1–5）**：相关性、新颖性、可信度三档打分。
- **分层指标**：按类型标签（verb_form/idiom/slang…）分别统计，看哪类最难。
- **消融实验**：逐步去掉“统计过滤/语义漂移/LLM 终判”某一级，看 F1 变化，验证每一级的实际贡献——与你论文“模块贡献”思路一致。

### 2.3 优先级建议

先做**自建 gold set**（最贴合你的词库、成本最低），再抽 **EPIE / VNC** 做通用性验证；用 F1 + Recall@K + 人工评分三件套即可起步，不必一开始就上全套基准。

## 3. 标签粒度（决策点 4，用户给出新思路）

用户思路：需要分类，但不至于这么多大类；**大类下带小类**。最终定为两大类：

### 大类 A · 语义衍生 / 抽象引申

原理：生僻意思导致“无厘头”或“抽象扩展词义”的衍生。

| 小类 | 说明 | 示例 |
|------|------|------|
| 生僻义 / 引申义 | 低频但重要的引申义 | mine 的引申义 |
| 习语 idiom | 整体义 ≠ 字面组合 | make ends meet |
| 俚语 slang | 口语/非正式固定表达 | spill the beans |
| 名词短语 / 特殊搭配 | 名词短语、特殊搭配 | double-edged sword |

### 大类 B · 动词结构漂移

原理：词 + 小品词 / 词形变化导致，词和它的短语/变形完全不同。

| 小类 | 说明 | 示例 |
|------|------|------|
| 短语动词 phrasal_verb | 中文释义区分「字面直译」与「真实含义」 | turn → turn up（字面“向上转” vs 真实“出现/调大”） |
| 动词变形漂移 verb_form | 变形后语义/词性变 | give → given（句首“鉴于”） |

边界：B 类不收普通固定介词搭配（如 satisfy with 这类字面可推），只收真正改变语义的。原「词源/同族」移出“拓展”标签（同根词已有独立列，词源仅作多语言桥接）。

## 4. 多语言原则（决策点 7，先记录）

- 算法主干（召回→过滤→语义漂移→终判）**语言无关**，可复用到任何字母语言。
- 每种语言只需替换：词形还原器、表达库/词典、统计语料、向量模型语种、语法规则（如法语性数配合、连字符）。
- 词源知识图谱（unified-etymology-graph 覆盖 5529 语言）可做跨语言同族桥接。
- 节奏：先英语跑通闭环，法语作为第一个验证“同框架换数据”的语言；不提前实现。
