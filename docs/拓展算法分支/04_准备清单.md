# 完成“智能拓展词典”算法所需的知识 / 理论清单

> 日期：2026-08-18（更新版）
> 范围：只回答“完成这个算法，我需要掌握哪些**算法侧的知识/理论**”。
> 排除项：语言知识不列（不是学语言，是开发算法；语法只作为算法内部特征使用）；编程知识不列（工程实现可交助手完成）。

## 0. 说明

本清单按“它在漏斗里用在哪一步”组织，只列算法/数学/理论，不列语言学学习、不列编程实现。资源（数据/样本/基底/模型）单独见 §1。

## 1. 资源库清单（数据 / 样本 / 基底）

### 1.1 表达库（算法底座，开源可分发）

- [ ] DANTE（42k 词目 + 23k 多词表达 + 27k 习语）
- [ ] ECDICT（本地 77 万条，词形/变体/短语兜底）
- [ ] reference_phrasal_verbs.json（自有，3217 条短语动词）
- [ ] unified-etymology-graph（词源同族，覆盖 5529 语言）

- [ ] WordNet（词义/同反义/上下位/派生）
- [ ] 法语 Wiktionary / 开放法语词典（法语阶段再加）

### 1.2 本地可选增强（用户自备，不随开源发布）

- [ ] McGraw-Hill 习语包（22,209 条，个人/非商业）
- [ ] 牛津 / 朗文 / 柯林斯（用户自购或自备）

### 1.3 语料（用于统计量计算）

- [ ] 英语语料：BNC / COCA 子集、或 Wikipedia dump 采样、或 Gigaword 子集
- [ ] 法语语料（法语阶段）：frWaC / OSCAR 法语子集

### 1.4 评测集

- [ ] 自建金标准 gold set：GRE/雅思词库抽样 100–300 词人工标注（优先）
- [ ] EPIE Corpus（717 习语 / 25,206 句）
- [ ] VNC-Tokens（动词-名词搭配字面/非字面）
- [ ] SemEval-2013 Task 5b（习语检测）
- [ ] DiMSUM / PARSEME（多词表达标注）

### 1.5 模型与工具（实现层，可交助手）

- [ ] 词形还原：Lemminflect / spaCy / Stanza
- [ ] 句子/词向量：MiniLM / BGE；可选 API embeddings
- [ ] 向量索引：FAISS / hnswlib
- [ ] 知识图谱：小规模 SQLite/NetworkX；规模化 Neo4j/NebulaGraph
- [ ] RAG/GraphRAG 框架

## 2. 需要的知识 / 理论（算法侧，按漏斗步骤映射）

| 知识 / 理论 | 对应漏斗步骤 | 作用 |
|-------------|--------------|------|
| 概率统计 + 信息论 | 阶段 3 过滤 | MI、LLR、T-score、Dice 的本质：判断搭配是否“固定/非字面” |
| 线性代数 | 阶段 4 语义漂移 + 向量检索 | 向量/矩阵、余弦相似度、嵌入几何、PQ 量化（呼应 HNSWPQ） |
| 机器学习 / 表示学习 | 阶段 4 + 阶段 5 | 词嵌入、上下文嵌入（BERT）、对比学习（习语表征） |
| 信息检索 / 近似最近邻 | 阶段 2 召回 + 评测 | 倒排索引、HNSW/PQ/ADC、召回-重排、Precision/Recall/F1/MRR/Recall@K |
| 图论 + 知识图谱 | 阶段 1 + 阶段 2 | 词关系图、多跳推理、GraphRAG |
| 词义表示与归纳（WSI/WSD） | 大类 A 生僻义 | 上下文聚类、一词多义归纳 |
| 多信号融合 / 排序 / 级联 | 整体漏斗 | 把召回→过滤→排序串成漏斗，权重与阈值 |

说明：语法（词性 POS、词形 lemma、依存）只作为算法内部输入特征，由工具/模型处理，不构成“学语言”的要求。

## 3. 对应的课程 / 自学材料（算法侧）

- 概率统计 / 信息论：Manning & Schütze《Foundations of Statistical Natural Language Processing》（搭配统计 MI/LLR 章节）
- NLP / 表示学习：Stanford CS224N（NLP）、CS224U（NLU）
- 信息检索：Manning《Introduction to Information Retrieval》检索部分；结合你已有的 HNSWPQ 论文
- 知识图谱 / RAG：Microsoft GraphRAG（arXiv 2404.16130）
- 词义归纳 / 词义漂移：CoKE 论文、Periti & Tahmasebi 2024（Lexical Semantic Change 综述）
- PIE 基准：Haagsma et al. 2019《Casting a Wide Net》

## 4. 与申请目标的衔接（作品集叙事）

这个算法可作为“NLP + 检索 + 知识图谱”的完整作品，和你 HNSWPQ 的检索背景形成连贯叙事：从“向量检索优化（HNSWPQ）”到“检索增强的词知识系统（KTRT 拓展算法）”。写进简历需能讲清方法、局限、评测，不做夸大。

## 5. 最小启动闭环

1. 英语 + GRE + 自建 100 词金标准，跑通六阶段；
2. 用 F1 + Recall@K + 人工评分做首轮评测；
3. 再以法语验证“同一框架 + 换语言数据库/语法规则”。
