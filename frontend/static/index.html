操作指南

快速开始

  1. 导入词库

    点「导入」，选择一个 xlsx 文件即可。GRE、雅思、考研词库在压缩包的 wordbooks 文件夹里。

  2. 填写 API Key

    在「设置」填入你自己的 Key 并保存。不填也能背词，只是不能用 AI 造句和添加新词。

  3. 开始学习

    「学词」背单词，「杀词」闯关，答错自动进错题本。
