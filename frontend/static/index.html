⚠️ 使用须知 · 避坑指南（怎么容易把程序搞崩）
  • 不要同时双击启动多个 KTRT 实例——会抢数据库锁，出现「导入失败 / failed to fetch」。
  • 程序运行时不要删除或移动 data 目录下的 xlsx、ktrt.db、tts_cache。
  • 导入 Excel 前先关闭 Excel / WPS，避免文件被占用导致导入失败。
  • 不要手动编辑 ktrt.db；删词、清进度请用管理页/导入页的按钮。
  • 杀毒软件或网盘同步不要实时扫描 C:\KTRT\data（会锁文件、拖慢甚至中断服务）。
  • 出现异常后查看 C:\KTRT\launcher.log，把最后几行发给开发者最有效。
  • 升级/重装前先备份 data 目录——词库、进度、收藏、造句全在里面。
