# 品牌图目录（自备素材）

把你自己准备的字标图放进来，程序会按"页面质感 + 配色"自动切换；
**没有文件时自动退回内置文字字标**（KTRT / 溯源词斩），所以不放也能正常用。

文件名必须完全一致（**SVG 矢量**，透明底，高度建议 60–120px，宽高比任选）：

| 文件名 | 用在 |
|---|---|
| `brand-neon.svg` | 科幻 · 霓虹 |
| `brand-acid.svg` | 科幻 · 酸黄 |
| `brand-matrix.svg` | 科幻 · 矩阵 |
| `brand-minimal.svg` | 简约（可选） |
| `brand-paper.svg` | 纸质（可选） |

> 用 SVG 是因为矢量在任何缩放下都清晰；PNG 请先转成 SVG（或告诉我，我把加载器改成同时支持 PNG）。

## 换图

直接用同名文件覆盖即可（SVG 优先，PNG 兜底）；删掉图后界面会自动退回内置文字字标。
