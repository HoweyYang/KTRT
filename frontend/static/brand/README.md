# 品牌图目录（自备素材）

把你自己准备的字标图放进来，程序会按"页面质感 + 配色"自动切换；
**没有文件时自动退回内置文字字标**（KTRT / 溯源词斩），所以不放也能正常用。

文件名必须完全一致（**SVG 矢量**，透明底，高度建议 60–120px，宽高比任选）：

| 文件名 | 用在 |
|---|---|
| `brand-neon.svg` | 科幻 · 霓虹（例如银翼杀手风格字标） |
| `brand-acid.svg` | 科幻 · 酸黄（例如赛博朋克 2077 风格字标） |
| `brand-matrix.svg` | 科幻 · 矩阵（例如黑客帝国风格字标） |
| `brand-minimal.svg` | 简约（可选） |
| `brand-paper.svg` | 纸质（可选） |

> 用 SVG 是因为矢量在任何缩放下都清晰；PNG 请先转成 SVG（或告诉我，我把加载器改成同时支持 PNG）。

## 为什么这个目录里没有图

电影 / 游戏的原版 logo 属于版权与商标素材（华纳、CDPR 等）。
本项目是公开仓库且会发布安装包，**内置这些素材会有商标风险**，
因此这里只提供"放图就能用"的机制：

- 自己本地用：把图丢进来即可；
- 该目录下的图片默认**不进 git**（见 `.gitignore`），所以公开发布不受影响。
